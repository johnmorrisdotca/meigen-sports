# 人物リスト（国と競技ごとに2,000人）

[`data-sources/people.csv`](../data-sources/people.csv) は、このパッケージが事実を組み立てる人物のリストです。[priority-athletes.ja.md](priority-athletes.ja.md) の最初のリスト（1,000行、重複が1人いて999人）に、さらに1,001人を足し、46か国のどの国の読者も、米国だけでなく、たいていの競技で知っている人に出会えるようにします。人物は Wikidata の項目（QID）です。名前では人物を特定せず、1人は1回だけ載せます。

| 列 | 意味 |
| --- | --- |
| `qid` | Wikidata の項目。最初のリストでまだ項目がない行だけ空です。 |
| `name` | 英語の名前 |
| `sport` | 競技コード（例: `judo`、`figure_skating`、`ice_hockey`） |
| `country` | 国籍の国（ISO 3166-1 の2文字コード）。46か国のどれにも当てはまらなければ空 |
| `priority` | `1` は最初のリスト、`2` は 0.4.0 で足した人 |
| `tier` | `existing`、または `A`、`B`、`C`、`H`（下記） |
| `sitelinks` | その人の Wikipedia の言語版の数 |
| `olympic_medals` | その国・競技のオリンピックのメダル一覧で見つかったメダルの件数 |
| `enwiki_title` | 英語版 Wikipedia の記事 |
| `birth_on`、`death_on` | Wikidata に日まであるときだけ、完全な日付。なければ空 |
| `source` | 出どころ。Wikidata の項目と英語版 Wikipedia の記事 |

記録しないもの: 性別、民族、宗教、健康（パラの印、障害の区分、分類の符号を含む）、家族、政治。

## 選び方

スクリプトは `pipeline/people/select_people.py` です。同じ材料からは同じリストになります（`--check`）。

1. **候補。** 国と競技ごとに、国籍（P27）がその国（またはその前身の国。ロシアにはソ連、ドイツには東西ドイツ、チェコスロバキア、ユーゴスラビア）で、競技（P641）がその競技の Wikidata の人物のうち、言語版の多い上位50人。それに、英語版 Wikipedia の`List of Olympic medalists in ...`にある、その国・その競技のオリンピックのメダリスト（色は問わず、団体のメダルは名前の挙がった全員に数えます）。全員に英語版 Wikipedia の記事が必要です。
2. **層。** A は、その国・競技でオリンピックのメダルが1件以上。B は Wikipedia の言語版が20以上。C は8以上で、その国・競技の人数が3人に満たない間だけ使います。H は、国ごとの巡の前に入れる、英語版 Wikipedia の栄誉リストの人です（いまは NBA の50人。うち37人が新規）。
3. **得点。** 国・競技の中で、言語版の数に、メダル1件につき10を足します（数えるのは最大5件）。同点は QID の番号が小さいほうが先です。
4. **釣り合い。** 最初のリストを先に数えます。そのうえで国ごとに新しく足す人数の枠があります（日本とカナダは70、米国は45、ドイツ・フランス・イタリア・英国は55、最初の14か国の残り7か国は40、その他は6から12。`people_config.py`）。国の中では、1巡目はまだ1人もいない競技の最良の未掲載者、2巡目は2人に満たない競技、と進めます。国は1人ずつ順番に回すので、ある国が先に枠を使い切ることはありません。2,000人で止まります。
5. **Wikidata の記述での確認。** 項目が人間（P31 = Q5）であること。国籍の記述があればその国のものであること。オリンピックのメダルの件数がある人（A 層）を除き、運動選手の職業（P106）があり、競技の外の職業（俳優、政治家、作家、歌手、実業家など）がないこと。言語版の数だけでは、マラソンを走る小説家が、その競技の選手より上に来てしまうからです。外れた人は除き、次の候補が入ります。理由は `data-sources/people-rejected.csv` にあります（312人を除きました）。代わりに、俳優や政治家としても有名な選手は、メダリストでない限り外れます。

## 覚えではなく、確かめたもの

競技と国の項目はすべて Wikidata から読み戻して名前と照合します（`fetch_people.py verify`）。以前の取得には、名前と違う競技の項目が混ざっていました。John が例に挙げた2人も同じように確かめました。Nicolas Gill（Q3277632、柔道、カナダ、メダル一覧に記載）と Christa Deguchi（Q52133654、柔道、カナダ。Wikidata では名の綴りは C で始まります）。

## 結果

46か国、171の競技コード（最初のリストには細かいものが多い）で2,000人です。新しく足した1,001人は A 層446、B 層231、C 層286、H 層37で、約99.6%に完全な誕生日があります。最初の14か国には40から70人、そのほかの国には6から12人を足しました。たとえば柔道には、カナダの Nicolas Gill、Christa Deguchi、Catherine Beauchemin-Pinard が載ります。日本、カナダ、ドイツ、フランス、イタリア、英国のどの国にも、陸上、フィギュアスケート、水泳、体操、サッカー、バスケットボール、テニス、自転車、ボクシング、柔道の人がいます。国と競技ごとの人数は `data-sources/people-coverage.csv` にあります。

Wikidata の記述はそのまま使うので、少数は誤りです（遊びでやった競技に入っている人など）。最初のリストからは、パラの印を外しました（`para_swimming` などはふつうの競技名になり、二重に載っていた1人は1回だけにしました）。

## まだできていないこと

- 世界王者と殿堂入りは別の出典にしていません。言語版の数でだけ拾っています。
- パラリンピックのメダリストもほかの栄誉と同じ扱いですが、その一覧はまだ読んでいません。パラの印で人を選ぶことはありません。
- もっと広い上位の層（2万から4万人ほど）は、`MEIGEN_SEARCH_PAGES` を上げて取り直します。[pipeline/people/README.md](../pipeline/people/README.md) を見てください。
