# 有名さの順位リスト：2,000人を世界での有名さで並べる

[`data-sources/priority-people.csv`](../data-sources/priority-people.csv) には2,000人が載っています（[優先する人物](priority-people.ja.md)）。その全員に、同じファイルから誰でも計算し直せる点数で、1位から2000位まで順位をつけています。この順位がパッケージの「有名さ」のものさしです。`significance` が読み（誕生日と命日の事実の `fameRank`）、ショーケースの先頭80人の誕生日もここから取り、`catalogue.json` にも載せます（上位100人は[中身の一覧のページ](https://johnmorrisdotca.github.io/meigen-sports/catalogue.html)、2,000人の全部はファイルの `fame` の中）。

## 点数

整数で、ファイルの列と [`data-sources/fame-rule.json`](../data-sources/fame-rule.json) の重みから決まります。

```
score = editions
      + 2 * min(olympic_medals, 5)
      + 4 * min(world_titles, 3)
      + 8 * min(hall_of_fame, 2)
```

| 部分 | 意味 | 出どころ |
| --- | --- | --- |
| `editions` | その人の記事があるウィキペディアの言語の数。いちばん大きい部分で、1から197まであります。 | Wikidata（CC0）。2026年11月3日に読みました |
| `olympic_medals` | オリンピックのメダルの数（色は問いません）。数えるのは5個まで（1個2点、最大10点）。578人にあります。 | 英語版ウィキペディアのメダリスト一覧（CC BY-SA 4.0） |
| `world_titles` | 世界チャンピオンを表す Wikidata の「受賞」。数えるのは3つまで（1つ4点、最大12点）。30人にあります。 | Wikidata（CC0） |
| `hall_of_fame` | 殿堂を表す Wikidata の「受賞」。数えるのは2つまで（1つ8点、最大16点）。356人にあります。 | Wikidata（CC0） |

足せる点は最大38点なので、100の言語で知られる人が、60の言語で知られる人に抜かれることはありません。数えるのはメダルの数で、金メダルだけではありません。一覧に色が書かれていないことと、Wikidata の出場の記録にばらつきが大きいことが理由です（マイケル・フェルプスは0個になってしまいます）。世界タイトルと殿堂は Wikidata にある分だけです（競技によっては少なめです）。書かれていなければ0点で、引かれることはありません。

**同点のとき。** 点数が同じなら、最初のリストでの位置（`old_rank`、1〜999）の順、それも同じなら Wikidata の番号の順です。昔の順番は同点のときだけ使い、最低の位置としては使いません。最初の999人のうち232人は前の位置と同じかそれより上、767人は下で、あとから足した人のうち187人が500位以内にいます。

**点数がつかない人。** 39人は点数をつけられないので、最初のリストでの位置をそのまま保ちます（理由は `fame_note` に書いてあります）。30人はまだ Wikidata の項目がなく、9人は同じ名前の別の人（政治家や女優）の項目につながっています（変換の処理も同じ9人を除いています）。当てずっぽうでは順位をつけず、リストには残します。

## 偏りの確認

国や競技が順位を独り占めしていないか調べます（国は Wikidata でその人が代表する国、なければ46か国のうち最初の国籍です）。決まりは [`fame-rule.json`](../data-sources/fame-rule.json) にあります。2,000位まで、100位ごとのまとまりで、1つの競技は35人まで、1つの国は45人まで。超えそうな人は、収まる次の位置まで待ちます。**動かされた人はいません。** 点数だけで限度の中に収まっています（`pipeline/people/fame.py check` と `test/fame.test.ts` が、超えたら失敗します）。

| 順位 | 国（多い順） | 競技（多い順） | 国の数 / 競技の数 |
| --- | --- | --- | --- |
| 1〜20位 | 米国6、アルゼンチン2、ドイツ2、ブラジル2、フランス2 | サッカー8、テニス4、ボクシング2 | 10 / 9 |
| 1〜100位 | 米国37、ドイツ7、ブラジル5、スペイン4、オランダ4、英国4、ロシア4 | サッカー32、テニス21、ボクシング7、バスケットボール7、陸上7、F1 5 | 29 / 17 |
| 1〜500位 | 米国151、カナダ31、ドイツ23、ロシア22、英国21 | サッカー69、陸上61、テニス50、バスケットボール49、プロレス34 | 46 / 52 |
| 1〜2000位 | 米国414、カナダ192、日本102、英国89、フランス86 | アイスホッケー163、バスケットボール121、野球121、陸上102、サッカー77 | 46 / 171 |

上位は世界の顔ぶれで、いちばん多くの言語で知られているサッカーとテニスが先頭に来ます。米国は上位100人の約3分の1、2,000人全体の約5分の1です。上位100人のうち4人は、リストの46か国にない国の人です（たとえばポルトガル）。リストは John が選んだ最初の999人と、国と競技ごとに選んだ1,001人なので、どちらにも入っていない人は順位がつきません。

## 順位の使いみち

- 誕生日と命日の `significance` は、1〜100位で50、300位まで45、700位まで38、1,200位まで28、2,000位まで18を足します（`fameRank`。`priorityAthlete` だけがついた古い事実は、これまでどおり一律45）。その人のページの言語の数による加点（最大75）はそのまま足されます（順位づけの説明は ranking.md）。
- 事実のメタデータ `meta.topFamous` は、このリストの先頭80人で、`feeds/showcase.json` が彼らの誕生日を載せます。昔の `extract_wikidata_famous.json`（有名な約500人の取得で、このリストの一部）はなくなりました。
- リストにいる人のすべての事実で `priorityAthlete` は真、`fameRank` はその人の順位です。

## 再現するには

```sh
python3 -I pipeline/people/fame.py fetch    # Wikidata。1回に1リクエスト（2,000人で64回）。ファイルは MEIGEN_PEOPLE_RAW の下に残る
python3 -I pipeline/people/fame.py rank     # fame_score と fame_rank を書く
python3 -I pipeline/people/fame.py check    # ファイルが列どおりか、偏りの決まりが守られているか
python3 -I pipeline/people/test_fame.py
```

使わないもの：性別、民族、宗教、健康、家族、政治。出どころ：Wikidata（CC0）と英語版ウィキペディアのメダリスト一覧（CC BY-SA 4.0）。Sports Reference と ESPN は使いません。
